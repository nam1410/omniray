Every cloud is a point cloud in the camera frame of the single input image and is drawn with no rotation applied. Each method is evaluated at the same set of pixels, so the four clouds have the same points and the same colours and differ only in where those points were placed. Monocular reconstruction is recovered only up to a global scale, and the methods write out at very different scales, so every cloud is recentred on its median point and scaled so that its 90th-percentile radius is 1 at render time only; the .ply files keep their original coordinates.

02In-the-wild images
